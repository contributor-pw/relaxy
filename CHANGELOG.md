# CHANGELOG

## 1.1.0 - 2026-08-03

### Изменено

- Второй домен (`DOMAIN_2`) переведён со статического апстрима `site-2` на
  `mp-max-directus:8055` — стенд Directus для проекта МП Макс.
- В блоке второго домена добавлена поддержка websocket (`proxy_http_version 1.1`,
  заголовки `Upgrade` и `Connection`) — Directus держит на нём realtime-подписки.
- `client_max_body_size` для второго домена поднят до `64m`: загрузка выгрузок
  идёт файлами в десятки мегабайт, дефолтного `1m` не хватает.
- В начало `nginx.conf.template` добавлен `map $http_upgrade $connection_upgrade`,
  чтобы заголовок `Connection: upgrade` выставлялся только для апгрейд-запросов.

### Обновлено

- `README.md`: раздел про второй домен описывает смену апстрима и требования
  websocket-приложений.
